# Chat Utils

## Purpose
Utilities for AI chat functionality across different contexts (sandbox, career quest, challenges).

## Files
| File | Purpose |
|------|---------|
| `check-cq-code.ts` | Check career quest code with AI |
| `delete-career-chat.ts` | Delete career chat history |
| `delete-challenge-chat.ts` | Delete challenge chat history |
| `delete-sandbox-chat.ts` | Delete sandbox chat history |
| `request-cq-hint.ts` | Request AI hint for career quest |
| `send-career-message.ts` | Send message in career chat |
| `send-challenge-chat-message.ts` | Send message in challenge chat |
| `send-sandbox-message.ts` | Send message in sandbox chat |
| `stop-chat-stream.ts` | Stop streaming chat response |
