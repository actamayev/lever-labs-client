# Constants

## Purpose
Application-wide constants and configuration values.

## Files
| File | Purpose |
|------|---------|
| `arcade-games-map.tsx` | Arcade games configuration/mapping |
| `constants.ts` | General app constants (key mappings, etc.) |
| `display-constants.ts` | LED display dimensions and pre-defined designs |
| `listeners-map.ts` | Event listener mappings |
| `page-constants.ts` | Page/route constants |

## Subdirectory
- `career-quest/` - Career quest specific constants
