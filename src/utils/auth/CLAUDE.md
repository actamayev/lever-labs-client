# Auth Utils

## Purpose
Authentication-related utilities including validation, schemas, and submission handlers.

## Files
| File | Purpose |
|------|---------|
| `auth-schemas.ts` | Zod validation schemas for auth forms |
| `confirm-login-fields.ts` | Validate login form fields |
| `confirm-register-fields.ts` | Validate registration form fields |
| `is-email-valid.ts` | Email format validation |
| `logout.ts` | Logout handler |

## Subdirectories
- `google/` - Google OAuth utilities
- `submit/` - Form submission handlers
