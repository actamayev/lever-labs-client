# Career Quest Utils

## Purpose
Utilities for Career Quest feature including navigation, triggers, progress saving, and content management.

## Files
| File | Purpose |
|------|---------|
| `career-quest-trigger.ts` | Send triggers to robot during career quest |
| `create-media-helpers.ts` | Helper functions for media content |
| `edit-career-quest-sandbox-project.ts` | Edit sandbox projects in career quest |
| `is-pip-connected.ts` | Check if pip device is connected |
| `navigation-helpers.ts` | Slide navigation utilities |
| `react-node-to-string.ts` | Convert React nodes to strings |
| `retrieve-full-career-data.ts` | Fetch complete career quest data |
| `save-career-progress.ts` | Save user progress |
| `stop-career-trigger.ts` | Stop active career triggers |

## Subdirectories
- `career-quest-left-content/` - Left panel slide content components
- `career-quest-right-content/` - Right panel slide content components
