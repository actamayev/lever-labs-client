# Personal Info Utils

## Purpose
Utilities for user profile and settings management.

## Files
| File | Purpose |
|------|---------|
| `change-password.ts` | Change user password |
| `edit-name.ts` | Edit display name |
| `edit-username.ts` | Edit username |
| `remove-current-profile-picture.ts` | Remove profile picture |
| `retrieve-personal-info.ts` | Fetch user profile data |
| `set-default-site-theme.ts` | Set light/dark theme preference |
| `set-sandbox-notes-open-status.ts` | Toggle sandbox notes panel |
| `upload-profile-picture.ts` | Upload new profile picture |
