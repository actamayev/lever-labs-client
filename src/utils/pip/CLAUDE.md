# Pip Utils

## Purpose
Utilities for Pip robot device connection and management.

## Files
| File | Purpose |
|------|---------|
| `disconnect-from-pip.tsx` | Disconnect from pip device |
| `pip-turning-off-serial-disconnection.ts` | Handle serial disconnection on pip power off |
| `request-to-connect-to-pip.ts` | Request connection to a pip |
| `search-for-pip-by-uuid.ts` | Search for pip by UUID |
| `search-pip-by-uuid-util.ts` | Utility for pip UUID search |
| `set-serial-connection-status.ts` | Update serial connection status |
| `stop-polling-sensors.ts` | Stop sensor data polling |
