# Quest Utils

## Purpose
Utilities for quest/lesson functionality including answer submission and data retrieval.

## Files
| File | Purpose |
|------|---------|
| `mark-lesson-complete.ts` | Mark a lesson as completed |
| `retrieve-all-lessons.ts` | Fetch all available lessons |
| `retrieve-detailed-lesson.ts` | Fetch detailed lesson data |
| `shuffle.ts` | Array shuffle utility for randomizing answers |
| `submit-action-to-code-multiple-choice-answer.ts` | Submit multiple choice answer |
| `submit-action-to-code-open-ended-answer.ts` | Submit open-ended answer |
| `submit-block-to-function-answer.ts` | Submit block-to-function answer |
| `submit-fill-in-blank-answer.ts` | Submit fill-in-blank answer |
| `submit-function-to-block-answer.ts` | Submit function-to-block answer |
| `submit-matching-answer.ts` | Submit matching question answer |
