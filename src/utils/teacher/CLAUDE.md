# Teacher Utils

## Purpose
Utilities for teacher classroom management.

## Files
| File | Purpose |
|------|---------|
| `create-classroom.ts` | Create a new classroom |
| `edit-classroom-name.ts` | Rename a classroom |
| `edit-teacher-data.ts` | Update teacher profile |
| `request-become-teacher.ts` | Request teacher role |
| `retrieve-detailed-classroom-info.ts` | Fetch detailed classroom data |
| `retrieve-teacher-classrooms.ts` | Fetch teacher's classrooms |
| `update-display-status-all-students.ts` | Toggle display for all students |
| `update-driving-status-all-students.ts` | Toggle driving for all students |
| `update-individual-student-display-status.ts` | Toggle display for one student |
| `update-individual-student-driving-status.ts` | Toggle driving for one student |
| `update-individual-student-lights-status.ts` | Toggle lights for one student |
| `update-individual-student-tones-status.ts` | Toggle tones for one student |
| `update-lights-status-all-students.ts` | Toggle lights for all students |
| `update-tones-status-all-students.ts` | Toggle tones for all students |

## Subdirectories
- `hub/` - Hub management utilities
- `scoreboard/` - Scoreboard management utilities
