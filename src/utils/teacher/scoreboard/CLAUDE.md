# Scoreboard Utils

## Purpose
Utilities for classroom scoreboard/team management.

## Files
| File | Purpose |
|------|---------|
| `add-student-to-scoreboard.ts` | Add student to a team |
| `create-scoreboard.ts` | Create new scoreboard |
| `delete-scoreboard.ts` | Delete a scoreboard |
| `remove-student-from-scoreboard.ts` | Remove student from team |
| `update-scoreboard-team-score.ts` | Update team score |
| `update-scoreboard-time.ts` | Update scoreboard timer |
| `update-team-driving-status.ts` | Toggle team driving |
| `update-team-lights-status.ts` | Toggle team lights |
