# Blockly Utils

## Purpose
Blockly visual programming editor configuration, custom blocks, and code generation utilities.

## Files
| File | Purpose |
|------|---------|
| `initialize-blocks.ts` | Initialize all custom Blockly blocks |
| `order.ts` | Operator precedence for code generation |
| `rgb-to-hex.ts` | Color conversion utility |
| `strip-blockly-positions.ts` | Remove position data from Blockly JSON |
| `toolbox-config.ts` | Configure Blockly toolbox |
| `workspace-config.ts` | Configure Blockly workspace settings |

## Subdirectories
- `categories/` - Toolbox category definitions
- `custom-blocks/` - Custom block definitions and generators
