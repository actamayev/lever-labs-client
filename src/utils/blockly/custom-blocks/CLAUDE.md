# Blockly Custom Blocks

## Purpose
Custom Blockly block definitions and C++ code generators for robot programming.

## Files
| File | Purpose |
|------|---------|
| `create-all-blocks.ts` | Aggregate and register all custom blocks |
| `manual-traversal.ts` | Manual block tree traversal utilities |
| `button-blocks.ts` | Button input blocks |
| `led-blocks.ts` | LED/light control blocks |
| `motors-blocks.ts` | Motor control blocks |
| `sensor-blocks.ts` | Sensor reading blocks |
| `speaker-blocks.ts` | Speaker/audio blocks |

## Subdirectory
- `logic/` - Logic-related custom blocks
